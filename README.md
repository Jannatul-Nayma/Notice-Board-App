# 📖 Overview

The Notice Board App is a Java-based Android application developed to facilitate efficient communication between administrators, teachers, students, and staff. It provides a centralized digital platform for posting announcements, sharing event information, uploading eBooks, PDFs, and images, replacing the limitations of traditional physical notice boards.

The application aims to improve accessibility, information organization, and communication while reducing paper usage through digital information sharing.

---

# ✨ Features

- 👤 User registration and login
- 🔐 Secure administrator login
- 📢 View notices uploaded by the administrator
- 📝 Create and manage notices
- 🖼️ Access event images
- 📚 Download eBooks and PDF resources
- 🔒 Secure data storage and user privacy protection

---

# 🏗️ System Architecture

The application follows a **client-server architecture** consisting of:

- **Frontend:** Android user interface
- **Backend:** Firebase for data management
- **Database:** Stores text notices, images, and PDF documents
